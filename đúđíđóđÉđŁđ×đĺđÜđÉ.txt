РАПОРТ «КТО НЕ ЗАПОЛНИЛ ЧАСЫ» — НАСТРОЙКА В ПАНЕЛИ (вместо жёстких 17:00)
=======================================================================

1) Миграция (можно запускать повторно):
   psql -U postgres -d sasdb -f db/migration_hours_report.sql
   По умолчанию всё как сейчас: 17:00, каждый день, обе сводки, head — вся фирма, остальные — свои объекты.

2) Скопировать новые файлы:
   bot/hours_report.js
   public/raport-godzin.html
   public/js/raport-godzin.js

3) index.js — три вставки и одно удаление (файл на сервере может отличаться, поэтому правкой, а не заменой):

   а) после строки   const flow = require("./api/flow");
         const hoursReport = require("./bot/hours_report");

   б) после строки   app.use("/api/flow", flow.router);
      (обязательно ДО app.use("/api", apiRoutes);)
         app.use("/api/hours-report", hoursReport.router);

   в) после строки   flow.schedule(bot);
         hoursReport.schedule(bot);

   г) УДАЛИТЬ старый блок в scheduleReminder() — иначе отчёт придёт дважды:
         if (current === "17:00") {
           const key = `coord_report_${current}`;
           if (!sentThisMinute.has(key)) {
             await sendCoordinatorReports(bot);
             sentThisMinute.add(key);
             setTimeout(() => sentThisMinute.delete(key), 2 * 60 * 1000);
           }
         }

4) public/index.html — пункт меню (виден только админу):
   перед строкой с id="adminLink":
         <div id="hoursReportLink" class="nav-item" onclick="location.href='raport-godzin.html'" style="display: none">⏰ Raport godzin</div>
   и в нижний <script>, рядом с fetch('/api/flow/me' …):
         fetch('/api/hours-report/me', { headers: { 'x-session': localStorage.getItem('sas_session') || '' } })
           .then(function (r) { return r.ok ? r.json() : null; })
           .then(function (d) { if (d && d.is_admin) document.getElementById('hoursReportLink').style.display = ''; })
           .catch(function () {});

5) pm2 restart sas-bot

ЧТО ИЗМЕНИЛОСЬ
   • Пропуски «с начала месяца» считаются ДО ВЧЕРА — сегодняшний день не берётся (он ещё идёт).
     1-го числа — весь прошлый месяц. В заголовке видно период: «(01.10–08.10, без сьогодні)».
   • «Не заполнили вчера» — как было.
   • Отчёт уходит один раз в день: перезапуск pm2 не шлёт повторно; если сервер был выключен — уйдёт после включения
     (до 2 часов позже).
