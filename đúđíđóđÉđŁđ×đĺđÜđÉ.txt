KoorPanel у Telegram для координаторів — українська / русский

Що є:
  • кнопка «Panel» у чаті з ботом → мініпанель без пароля: головна (цифри дня), години з правкою, «Заявки»
    (розділи «Медогляд» і «Штрафи» — поки порожні, «Розділ у розробці»), перехід у повну панель;
  • привʼязка Telegram з панелі: внизу меню кнопка «✈️ Połącz Telegram» → одноразове посилання на бота (30 хв);
  • нові заявки на аванс і вихідні → координаторам обʼєкта (головний / з правом правки) з кнопками
    «Схвалити / Відхилити» + причина. Аванс — стандарт 300 zł. У вихідних — скільки людей уже вільні в ці дні.
    «Схвалити всі» — для вихідних. Рішення з панелі теж оновлює повідомлення в боті (хто і коли вирішив);
  • ранкова зведення о 07:30: хто сьогодні приїжджає, в кого останній день, без годин (поріг — як у щогодинних нагадуваннях, GAP_MIN_DAYS),
    що чекає рішення,
    у сб/нд — план набору; кнопки. Якщо подій немає — не надсилається;
  • план набору в неділю: замість старого текстового нагадування — таблиця на 3 тижні, «Підтвердити як є»
    (зберігає обʼєкти, де всі цифри є або є пропозиція з попереднього тижня), відсутні цифри — кнопками 0/1/2/3/5/Інше,
    «Пропустити» — заповнити в панелі. Якщо щось піде не так — старе текстове нагадування, як було;
  • пошук: координатор пише в бот прізвище (можна кирилицею) або ID → картка працівника
    (тільки свої обʼєкти, ID замаскований), години за місяць, історія;
  • команди: /panel — меню, /digest — зведення зараз, /s прізвище — пошук. Мова: кнопка в меню або УКР/РУС у мініпанелі.

Файли = GitHub dayoff-url 0086ad1 + ці зміни.

1) БАЗА. pgAdmin → db\migration_tg_coord.sql (весь файл, F5). Створює схему tgc (коди привʼязки, налаштування,
   надіслані повідомлення, стан діалогу). Таблиці панелі не змінюються. Можна запускати повторно.
   Унизу — список: у кого з координаторів Telegram уже є.

2) ФАЙЛИ — скопіювати в C:\sas-bot із заміною:
   нові:    api\tg.js, bot\coord.js, public\tg\index.html, public\tg\tg.css, public\tg\tg.js
   замінити:
     api\routes.js     — рішення по авансу / вихідних винесено у спільні функції (панель і бот), причина відмови з бота,
                         після рішення (і пакетного теж) оновлюються повідомлення в боті. Поведінка панелі та сама.
     api\flow.js       — неділя: нагадування про план набору — з кнопками (bot\coord.js), запасний варіант — старий текст.
     bot\handlers.js   — нова заявка на аванс / вихідні → повідомлення координаторам.
     public\index.html — кнопка «✈️ Połącz Telegram» над «Wyloguj».
     public\js\app.js  — та кнопка + відкриття сторінки за адресою index.html#page=advances (з мініпанелі).

3) index.js — ВСТАВКИ (файл не замінювати):

   а) поруч з іншими app.use("/api/..."), ОБОВʼЯЗКОВО ВИЩЕ рядка app.use("/api", apiRoutes);
        app.use("/api/tg", require("./api/tg").router);   // Telegram: мініпанель і привʼязка

   б) у app.post("/webhook", ...) — одразу ПЕРЕД рядком  await handleUpdate(bot, req.body);
        if (await require("./bot/coord").onUpdate(bot, req.body)) return;   // координатори: кнопки заявок, привʼязка, пошук
      (тобто після flow.onUpdate і referral.onUpdate)

   в) в кінці, поруч з flow.schedule(bot); medcheck.schedule(bot); …
        require("./bot/coord").schedule(bot);

4) .env — додати:
     TG_WEBAPP_URL=https://sas-panel.duckdns.org/tg/
     COORD_DIGEST_TIME=07:30
     ADVANCE_STD=300
   Необовʼязкові: COORD_DIGEST_ENABLED=0 — вимкнути ранкову зведення; COORD_NOTIFY=0 — не надсилати заявки в бот.
   Без TG_WEBAPP_URL усе працює, крім кнопки «Panel» і кнопок «Відкрити панель».

5) pm2 restart index
   Через ~30 с після старту всім координаторам, у кого Telegram уже є, ставиться кнопка «Panel»
   (у логах: [coord] menu button «Panel»: N/M). Далі — щодня о 04:10.

ПЕРЕВІРКА
   • Панель на компʼютері → «✈️ Połącz Telegram» → відкриється бот → Start → «Так, привʼязати».
     Кнопка стане «Telegram połączony ✓». Новий телефон — та сама кнопка, нове посилання.
   • У чаті з ботом зліва від поля вводу — кнопка «Panel» → мініпанель, зверху «Вхід через Telegram — без пароля».
     Якщо «Цей Telegram не привʼязаний» — зробити крок вище.
   • У бот: /panel — меню; написати прізвище працівника — картка.
   • Працівник просить аванс у боті → координаторам обʼєкта приходить картка з кнопками.
   • /digest — зведення одразу (не чекати 07:30).

Важливо
   • Координатори, у яких Telegram у панелі вже записаний, отримають усе одразу після рестарту:
     кнопку «Panel», ранкову зведення, заявки з кнопками. Вимкнути зведення — кнопка в меню бота (/panel).
   • Для координатора тепер /start показує меню координатора (раніше — вхід працівника). Якщо той самий Telegram
     уже увійшов як працівник — бот працівника лишається як був, координаторські — лише /panel, /s, /digest.
   • Рішення в боті — з тими самими правами, що в панелі (головний обʼєкт / право правки). «Тільки перегляд» — кнопки
     відповідають «Немає права редагування».
   • Сесії панелі живуть у памʼяті: після pm2 restart мініпанель сама входить знову (повна панель у браузері — як і раніше, логін).

Перевірено на копії тестової бази (60 перевірок): підпис Telegram (правильний / чужий токен / старий / підмінений),
привʼязка й повторний код, вхід, години (збереження через POST /api/hours, чужий обʼєкт 403), аванс → 3 координаторам →
відмова з причиною → працівнику його мовою → оновлено 4 повідомлення, схвалення в панелі (і пакетом) → оновлено в боті,
2 заявки на вихідні → «Схвалити всі» → URL у табелі, зведення і розсилка один раз о 07:30, меню / мова / пошук / картка
(чужого працівника не показує), план набору (Інше → 4·4·4, пропуск, повторне нагадування не йде), нагадування з мініпанелі,
відвʼязка. Мініпанель — у Chromium 390×844 (укр / рос).
