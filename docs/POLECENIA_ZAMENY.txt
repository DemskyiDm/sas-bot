«Poleć znajomego» — правки в существующих файлах
Каждая правка: НАЙТИ строку → вставить указанное ПОСЛЕ неё (или заменить, где сказано).

══════════════ index.js ══════════════

1) НАЙТИ:
const flow = require("./api/flow");
ВСТАВИТЬ ПОСЛЕ:
const referral = require("./bot/referral");

2) НАЙТИ:
app.use("/api/flow", flow.router);
ВСТАВИТЬ ПОСЛЕ:
app.use("/api/ref", require("./api/ref").router);

3) В обработчике app.post("/webhook" ...) НАЙТИ:
    if (await flow.onUpdate(req.body)) return;
ВСТАВИТЬ ПОСЛЕ (до await handleUpdate(bot, req.body);):
    if (await referral.onUpdate(bot, req.body)) return;

4) В конце файла НАЙТИ:
flow.schedule(bot);
ВСТАВИТЬ ПОСЛЕ:
referral.schedule(bot);
