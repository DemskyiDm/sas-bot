# Раздел «Rozmowy» — установка и работа

Оценка людей, задания координаторам на разговор, контроль разговоров, анкеты новым работникам.
Работает поверх раздела **Region** (нужна схема `reg`: кто отвечает за объект, красный ли объект).

Коротко:
- каждую ночь бот считает **бал риска** каждого работающего по уже имеющимся данным;
- в 8:00 (пн–пт) координатор получает в Telegram **до 5 человек** для разговора: кто, почему, что спросить;
- после разговора — **одна кнопка**: ✅ остаётся / ⚠️ проблема (жильё, деньги, график…) / 🚪 хочет уйти / 📵 не дозвонился;
- не закрыл за 2 рабочих дня — сообщение региональному; «хочет уйти» — региональному сразу;
- 10% закрытых разговоров бот **проверяет у работника**: «говорил ли с вами координатор?»;
- на 7-й и 30-й день координатор ставит новичку оценку 👍 😐 👎 (одна кнопка);
- работникам — **анкеты** на 3, 14, 30, 60 день и после ухода (кнопки, меньше минуты, 4 языка);
  тревожный ответ сразу создаёт срочное задание координатору.

| `bot/care.js` | Telegram: утренние списки, кнопки, анкеты, напоминания, эскалация, расписание. |

| `public/index.html`, `public/region.html` | Пункт меню «📞 Rozmowy» (в главном меню — только тем, кому модуль включён, и руководителям). |

## Установка на сервер (C:\sas-bot)

1. **Бэкап базы**: `pg_dump -Fc sasdb > sasdb_before_rozmowy.dump`.
2. **Миграция**: pgAdmin → Query Tool → открыть `db/migration_care.sql` → выполнить.
   Можно запускать повторно: настройки и тексты вопросов, изменённые в базе, не перезаписываются.
3. **Файлы** — скопировать новые: `bot/care.js`, `api/care.js`, `public/rozmowy.html`, `public/js/rozmowy.js`, `docs/ROZMOWY.md`.
   Изменённые (`bot/handlers.js`, `index.js`, `public/index.html`, `public/region.html`, `public/js/region.js`) —
   либо `git apply rozmowy.patch`, либо вставить руками:
   - **bot/handlers.js**, в `handleUpdate`, сразу после `if (!chatId) return;` в блоке `callback_query`:
     ```js
     // Розділ «Rozmowy»: завдання координаторам, анкети, перевірки
     if (/^(CR_|SV_|SC_)/.test(payload)) {
       await require("./care").handleCallback(bot, cq);
       return;
     }
     ```
   - **index.js**:
     ```js
     // после: const regional = require("./api/regional");
     const care = require("./api/care");

     // после: app.use("/api/regional", regional.router);   (перед app.use("/api", apiRoutes))
     app.use("/api/care", care.router);

     // в самом конце, после regional.schedule(bot);
     require("./bot/care").schedule(bot);
     ```
   - **public/index.html** — в меню перед «🚦 Region»:
     `<div id="rozmowyLink" class="nav-item" onclick="location.href='rozmowy.html'" style="display: none">📞 Rozmowy</div>`
     и в скрипт внизу, рядом с проверкой Region:
     ```js
     fetch('/api/care/me', { headers: { 'x-session': localStorage.getItem('sas_session') || '' } })
       .then(function (r) { return r.ok ? r.json() : null; })
       .then(function (d) { if (d && d.has_access) document.getElementById('rozmowyLink').style.display = ''; })
       .catch(function () {});
     ```
4. `pm2 restart sas-bot`.
5. **Включить координаторов**: панель → **📞 Rozmowy → 👥 Koordynatorzy** → отметить, кому включаем → «Zapisz».
   **После установки модуль выключен для всех** — ни задания, ни анкеты никуда не уйдут, пока вы не отметите людей.
6. Проверить: **⚙️ Ustawienia → «Przelicz ryzyko teraz»** — покажет, сколько людей посчитано
   и сколько анкет/оценок запланировано. Вкладка **Ryzyko** заполнится.

**Первый запуск.** Если поставить днём, утренний список не уйдёт сразу — он отправляется только с 8:00 до 11:00,
первые задания придут на следующий рабочий день. Анкеты — в 18:00 того же дня.
Чтобы запускать по частям: в Ustawienia `surveys_enabled = 0` (только задания) или `tasks_enabled = 0` (только анкеты).

## Кому включён модуль (👥 Koordynatorzy)

Отдельное меню для админа: список всех активных координаторов с галочкой, регионом, числом объектов и людей,
есть ли у координатора Telegram, **язык сообщений** и сколько у него открытых разговоров. Можно включать по одному (пилот) или
«Zaznacz wszystkich z obiektami».

- **Включён** — утром получает задания и оценки новичков, работники его объектов получают анкеты,
  сам видит раздел в меню панели.
- **Выключен** — ничего не получает, его работникам анкеты не идут, пункт «📞 Rozmowy» в меню скрыт.
  При выключении его открытые разговоры сразу отменяются (в Telegram кнопки пропадают с пометкой «скасовано»),
  запланированные анкеты не отправляются. Уже начатые анкеты работники могут дозаполнить.
- Включение действует со следующего утра (анкеты — с 18:00).
- **Язык** — на каком языке бот пишет координатору (украинский / русский / польский, по умолчанию украинский;
  хранится в `coordinators.lang`). Работники получают анкеты на языке, который сами выбрали в боте.
- Бал риска считается для всех — региональные и админ видят его в Ryzyko и для невключённых.
- Региональные и админ видят раздел всегда, даже если сами не включены как координаторы.

## Тест сообщений (🧪 Test)

Меню для админа, чтобы посмотреть и показать координаторам все сообщения модуля до запуска.

1. **Кому** — отметить координаторов (у кого есть Telegram). По умолчанию отмечены вы.
2. **Что** — утренний список (заголовок + 2 разговора), срочное из анкеты 🔔, поручение, оценка новичка 🌱,
   напоминание о просроченных, два сообщения региональному («хочет уйти», список просроченных);
   для работника — стартовый пакет при регистрации (6 вопросов: вопрос 1 «Как узнали о компании?» с 9 кнопками → имя → 2–6),
   анкеты 3/14/30/60 день и после ухода, напоминание об анкете, контрольный вопрос.
   Язык сообщений координатору — как в его настройках или любой из трёх; язык анкет — uk / ru / pl / en.
3. **«🧪 Wyślij test»** — всё уходит в Telegram с пометкой «🧪 ТЕСТ». Кнопки работают как настоящие:
   можно закрыть разговор, выбрать проблему, «↩️ Изменить», пройти анкету до конца.
   **Ничего не записывается** в задания, анкеты, оценки и статистику — только в служебную таблицу `care.test_msgs`.
4. **«Usuń»** — убирает тестовые сообщения из чата (по одному координатору или все сразу).
   Telegram разрешает боту удалять сообщения только 48 часов; более старые заменяются на «🧪 тест удалён» без кнопок.

Работает и для координаторов, которым модуль ещё не включён.

## Бал риска

Считается каждую ночь (после 5:00) по данным до вчерашнего дня. Всё настраивается в Ustawienia → Bal ryzyka.

| Сигнал | Баллы |
|---|---|
| NN за последние 14 дней | 10 за каждый |
| 2+ NN подряд | +15 |
| дней без часов (от 2, максимум 7; только на объектах, где часы вносятся) | 4 за день |
| часов за неделю меньше 60% от предыдущей | 10 |
| новичок (до 30 дней) | 15 |
| 60–80 день (перед порогом 80) | 15 |
| тревожный ответ в анкете за 21 день | 15 |
| оценка координатора 👎 / 😐 | 25 / 10 |
| объект красный в Region | 5 |

В список на разговор попадают люди с баллом **от 25**. У координатора одновременно открыто не больше **5** заданий:
утром свободные места заполняются людьми с самым высоким баллом. После разговора человек не попадает в список
14 дней («остаётся»), 7 дней («проблема»), 2 дня («не дозвонился»).

Не закрыто за **4 рабочих дня** — задание «пропущено» (видно в Kontrola), место освобождается.

## Что видит координатор

**Telegram, 8:00 (пн–пт):**
```
📋 Розмови на сьогодні: 5
Після розмови натисніть одну кнопку під людиною — це все, що потрібно.

👤 BOZHKO ILIIA · ID FG640417
🏭 HYDRO LODZ · 118-й день
Чому: 2 NN поспіль; 5× NN за 2 тижні
Спитайте: чому не виходить на роботу, що заважає; чому пропускає зміни
[✅ Залишається] [⚠️ Є проблема]
[🚪 Хоче піти]   [📵 Не додзвонився]
```
«⚠️ Є проблема» открывает второй ряд: житло / гроші / графік / колектив / дорога / інше.
После нажатия сообщение показывает итог и кнопку «↩️ Змінити» (в течение суток).
Незакрытые со вчера переносятся вниз нового списка. Тексты — на языке координатора (выбирается в 👥 Koordynatorzy: uk / ru / pl, по умолчанию uk).

**Панель → 📞 Rozmowy → Do rozmowy** — те же карточки и кнопки, плюс комментарий, оценки новичков,
кнопка «➕ Zleć rozmowę» (поручить разговор с конкретным человеком).

## Анкеты работникам

Через того же бота, на языке работника (`workers.lang`: uk / ru / pl / en), в 18:00.
Каждый вопрос — кнопки, следующий приходит после ответа. Не ответил — одно напоминание через сутки,
через 5 дней анкета закрывается.

| Анкета | Когда | Вопросы |
|---|---|---|
| d3 | 3-й день | жильё, дорога, объяснили ли работу, координатор на связи 🔒 |
| d14, d60 | 14 и 60 день | работа 1–5, жильё 1–5, планирует ли остаться, что мешает |
| d30 | 30 день | то же + оценка помощи координатора 1–5 🔒 |
| exit | после увольнения / rezygnacja | почему ушёл, помогал ли координатор 🔒, вернулся бы |
| start | **при регистрации в боте** — вопросы 2–6 стартового пакета | понятность условий 1–5, скорость рекрутера 1–5, жильё как обещали, оценка координатора 1–5 🔒, на сколько приехал |

**Стартовый пакет (6 вопросов).** Новый работник сразу после входа в бот получает один пакет:
вопрос 1 «Как вы узнали о компании?» (друг / координатор + имя, рекрутер, Facebook, Instagram, TikTok, Telegram, сайт вакансий, другое —
задаёт бот «Poleć znajomego») и сразу вопросы 2–6 — анкета `start` (нумерация 2/6 … 6/6). Расписание 18:00 её не отправляет.
- **Кто получает:** новые на объектах координаторов, включённых в 👥 Koordynatorzy. Остальные новые не получают ничего.
- **Галочка `start` в Rozmowy → Ustawienia** включает и выключает весь пакет (и вопрос 1 тоже).
- Напоминания вопросов 2–6 — раз в день 2 дня (число дней — Poleć znajomego → Ustawienia).
- «Жильё сильно отличается» — срочное задание координатору, даже если человек ответил до дня BHP.
- Ответ «на сколько приехал» копируется в Poleć znajomego (фильтр «Na ile», таблица по объектам).

- Первое сообщение анкеты говорит, кто видит ответы и что отвечать не обязательно (RODO).
- **Тревожный ответ** («нет» на вопросы 3-го дня, 1–2 по работе или жилью, «хочу уйти») — сразу срочное задание 🔔
  координатору (8:00–21:00, иначе утром). Если у объекта нет координатора — региональному.
- «Не совсем», «ещё не знаю», тройка, любая проблема — добавляют балл риска.
- 🔒 Вопросы о координаторе видят **только региональные и админ**: в сводке — суммарно, за 90 дней,
  от 5 ответов на координатора; по каждому работнику — в «Kto jak odpowiedział». Регионал не видит оценки
  самого себя. Координатор их не видит вообще.
- Тексты вопросов лежат в `care.questions` (JSON по языкам) — можно править в pgAdmin.

### Вкладка 📝 Ankiety

- **Каждая анкета отдельно.** Сверху карточки‑вкладки: Start, 3 dni, 14 dni, 30 dni, 60 dni, Po odejściu
  (в карточке — % ответов). Всё ниже относится только к выбранной анкете: тревожные ответы, распределение ответов,
  таблица объектов, кто как ответил. Раньше 14/30/60 дней с одинаковыми вопросами сливались в одну таблицу.
- **Obiekty** — колонки = вопросы выбранной анкеты: шкалы 1–5 — среднее (в скобках число ответов),
  остальные — доли ответов.
- **👤 Kto jak odpowiedział** — каждый работник отдельной строкой, ответ на каждый вопрос; фильтры
  «tylko z odpowiedziami», «tylko niepokojące», поиск; кнопка ⬇️ Excel. Для анкеты Start — ещё колонка
  «Skąd wie o nas» (канал и вписанное имя друга / координатора).
- **Клик по работнику** — карточка со всеми его анкетами (старыми и новыми) и тем, как он узнал о фирме.
- 🔒 Ответы о координаторе по каждому работнику видят **админ и региональные** (региональный — кроме ответов о себе самом);
  координатор их не видит ни в таблице, ни в карточке. Данные «кто привёл» координатор видит, только если в
  Poleć znajomego включено «Widoczne dla koordynatorów».
- **Меню.** В боковом меню Rozmowy есть блок «🤝 Poleć znajomego» (Odpowiedzi, Polecający, Źródła, Bezpieczeństwo, Ustawienia — по правам);
  отдельного пункта в главном меню больше нет. Кто видит только Poleć znajomego, попадает туда сразу по пункту «📞 Rozmowy».

## Kontrola

По каждому координатору за период: сколько заданий, % закрытых, % в срок (до эскалации), эскалации,
пропущенные, итоги ✅ ⚠️ 🚪 📵, доля «не дозвонился», проверка у работника («разговора не было»),
оценки новичков, % ответов на анкеты на его объектах, оценка от работников 🔒.

**Эффект** — главная цифра: из людей, у которых был сигнал риска до 80-го дня, сколько дожили до 80 дней
**с разговором** и **без**. Данные накапливаются с момента запуска: первые цифры — примерно через месяц.

## Кто что видит

- **Координатор** — свои задания, своих людей в Ryzyko, анкеты своих объектов (без вопросов 🔒),
  свою строку в Kontrola (без проверок у работников и оценок 🔒).
- **Региональный** — всё по своим регионам, поручения координаторам своего региона, вопросы 🔒 (кроме оценок себя).
- **Админ** — всё + 👥 Koordynatorzy + 🧪 Test + Ustawienia.
- **Координатор, которому модуль не включён**, раздела не видит.

## Telegram для региональных и админа

- «🚪 хочет уйти» — сразу, с именем, объектом и координатором;
- пн–пт 10:00 — список незакрытых дольше 2 рабочих дней (координатор тоже получает уведомление);
- срочное задание с объекта без координатора.
Для региона без регионального — админам.

## Важно

- Задания и уведомления идут только тем, у кого есть `telegram_chat_id`. Без него координатор работает в панели.
- Работники без бота не получают анкет (видно в Ankiety как «bez bota»).
- Даты считаются по польскому времени, независимо от часового пояса сервера базы.
- Все ежедневные задачи отмечаются в `care.job_runs`: перезапуск pm2 не приводит к повторной рассылке.
- Удалить раздел полностью: `DROP SCHEMA care CASCADE;` и убрать строки из `index.js` и `bot/handlers.js`.
