WYJAZDY: ОТПРАВКА КАРТИНКОЙ-ТАБЛИЦЕЙ + ПЛАН НАБОРА ПО ОБЪЕКТАМ + КРАСНЫЙ ПО ТЕМПУ
==============================================================================

1) Пакеты (один раз, в папке сервера C:\sas-bot):
   npm install @resvg/resvg-js@2.6.2 opentype.js@1.3.4
   Сборщик не нужен: для Windows ставится готовая версия.

2) Миграция (можно запускать повторно):
   psql -U postgres -d sasdb -f db/migration_flow_images.sql
   Делать ДО замены файлов: без неё сохранение получателей выдаёт ошибку.

3) Скопировать файлы (пути как в архиве):
   api/flow.js            — заменить
   api/flow_img.js        — новый
   assets/fonts/*         — новая папка: шрифт Inter (3 файла .ttf + лицензия OFL)
   public/js/wyjazdy.js   — заменить
   docs/WYJAZDY.md        — описание

4) pm2 restart sas-bot

НАСТРОЙКА (Wyjazdy → Ustawienia)
   «Forma dla koordynatorów» — Tekst / Obraz (tabela): для координаторов, которые получают сводку автоматически.
   Колонка «Forma» у каждого получателя в списке — так же.
   «Tempo naboru» — 20,40,60,80,100: сколько % плана недели нужно к концу пн, вт, ср, чт, пт (сб и вс — 100%).
   Тест: селектор «Tekst / Obraz» рядом с кнопками «🧪 … do mnie»; 🧪 в строке получателя берёт форму из этой строки.

ЧТО ПРИХОДИТ КАРТИНКОЙ
   Каждый день: 1) за день — объекты с движением сегодня + набор недели на сегодня;
                2) с понедельника — все объекты с планом или движением.
   Координатору и региональному фамилии идут в подписи (длинный список — отдельным сообщением).
   Понедельник: «Plan naboru» — таблица объект × 3 недели и статус (красный — не введён, жёлтый — не подтверждён);
                «Tydzień» — таблица прошлой недели.
   Больше 30 строк — несколько картинок альбомом.

ЕСЛИ КАРТИНКИ НЕ ПРИХОДЯТ
   Уходит обычный текст, в логе pm2: «[flow] картинка не вийшла …» — значит не выполнен шаг 1
   или нет папки assets/fonts. Если Telegram не принял картинку — эта часть уходит текстом.
